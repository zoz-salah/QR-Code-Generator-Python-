# GitHub QR Code Generator (Python)

## Overview
This is a simple Python project that generates a **QR code for a GitHub profile link** and saves it as an image file.  
The project is ideal for beginners who want to practice working with external libraries and file handling in Python.

## Features
- Generate a QR code for any GitHub profile URL
- Save the generated QR code as an image file
- Simple and easy-to-understand Python code
- Beginner-friendly project

## How It Works
1. The user provides a GitHub profile link instead of mine url.
2. The program generates a QR code from the link.
3. The QR code is saved as an image file on the local machine you select.
